\# AWS Capstone Project 4 — Containerized Flask Application



\## 1. Project Title



Containerized Flask Application using Docker, Amazon ECR and Amazon ECS



\## 2. Objective



The objective of this project is to containerize a Python Flask web application using Docker and deploy the containerized application on AWS using Amazon ECR and Amazon ECS with AWS Fargate.



\## 3. Technologies and AWS Services



\### Technologies

\- Python

\- Flask

\- Docker

\- HTML

\- Git

\- GitHub



\### AWS Services

\- Amazon ECR

\- Amazon ECS

\- AWS Fargate

\- IAM

\- Amazon VPC

\- Amazon CloudWatch
